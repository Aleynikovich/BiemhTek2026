FEATURES:
---------
✓ Clean, professional interface with frames and sections
✓ Connection management with visual status indicator
✓ Real-time robot status (program, vision, workpiece position)
✓ 8 program buttons with descriptive names
✓ Quick action buttons for common operations
✓ Scrollable console with timestamped, color-coded output
✓ Automatic status polling every 10 seconds
✓ Error handling and connection recovery

COLOR CODING:
-------------
● Green:  Connected / Success messages
● Red:    Disconnected / Error messages
● Orange: Warning messages
● Blue:   Current program indicator
● Black:  Info messages
