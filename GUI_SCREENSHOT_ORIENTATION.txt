KEY FEATURES SHOWN:

1. TABLE ENHANCEMENTS:
   - "Ori" column with arrow symbols: → (regular/0) or ↻ (180deg/1)
   - "Rx", "Ry", "Rz" columns showing all rotation angles
   - "Ref" column showing reference string (10, 11, 20, 21, 30, 31)
   - Shortened ID (last 8 digits)

2. VISUALIZATION ENHANCEMENTS:
   - Yellow arrows showing X+ tool axis direction
   - Arrow direction accounts for both Rz and orientation
   - Orientation 0: Arrow points forward (regular pick)
   - Orientation 1: Arrow points backward (180deg rotated pick)

3. CONTROL ENHANCEMENTS:
   - "Delete Selected" button (NEW) - removes single workpiece
   - "Clear Queue" button (FIXED) - now actually works

4. ORIENTATION REPRESENTATION:
   - Table: → or ↻ symbol
   - Visualization: Yellow arrow direction
   - Reference string: Last digit indicates orientation (10=ref1/ori0, 11=ref1/ori1)

Example workpiece readings:
- ID 12345678, Ref "10", Ori "→": Reference 1, picked regularly
- ID 23456789, Ref "11", Ori "↻": Reference 1, picked with 180° rotation  
- ID 34567890, Ref "20", Ori "→": Reference 2, picked regularly
- ID 45678901, Ref "21", Ori "↻": Reference 2, picked with 180° rotation
- ID 56789012, Ref "30", Ori "→": Reference 3, picked regularly

The yellow arrows on the canvas visually confirm the orientation!
